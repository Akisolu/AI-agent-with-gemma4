# Intrucciones de uso

- Instalar ollama en tu maquina
- Descargar gemma4:e2b o si prefieres otro modelo es valido, solo asegurate de cambiarlo en el codigo

- crear entorno virtual de python

```bash
    python -m venv .venv # En Windows
    python3 -m venv .venv # En Linux o Mac
```

- Iniciar entorno virtual

```bash 
    .venv\Scripts\Activate # En Windows
    source venv/bin/activate # En Linux o Mac
```

- Asegurate que el entorno este activado

``` bash
    (.venv) tu/directorio/actual
```

- Instalar depedencias

```bash 
    pip install -r dependencias.txt
```

- Ejecutar

```bash
    python main.py # En Windows
    python3 main.py # En Linux y Mac
```
